# 📑 **Overview**

This repository contains the **synthetic dataset** developed for our *AI-Powered Financial Advisory Capstone Project*.  
The dataset models realistic investor behaviour while ensuring **complete privacy**, **regulatory compliance**, and **reproducibility**.  

It supports the following system components:

- Multi-factor behavioural risk profiling  
- Machine-learning-based risk classification  
- Conversational AI financial advisory  
- Modern Portfolio Theory (MPT) portfolio construction  

The dataset is fully synthetic and contains **no real personal information**.

---

# 📌 **Why Synthetic Data?**

Real behavioural-financial datasets are:

- Proprietary (owned by banks/fintechs)  
- Regulated (KYC, GDPR, RBI norms)  
- Not publicly available for research  

Therefore, the dataset was generated using **synthetic-data engineering methods**, aligned with:

- IEEE Synthetic Data Frameworks  
- IEEE Privacy-Preserving ML research  
- Behavioural finance modelling literature  

This ensures **statistical realism**, **ethical integrity**, and **complete anonymity**.

---

# 🧠 **How the Dataset Was Created**

The dataset was generated using a **behavioural-statistical modelling pipeline**, informed by peer‑reviewed research.

### ✔ 1. Behaviourally Grounded Statistical Distributions  
Each attribute uses domain‑appropriate models:

| Feature | Distribution | Rationale |
|--------|--------------|-----------|
| Age | Normal / Logistic | Matches demographic patterns |
| Income | Log-normal | Economically realistic salary distribution |
| Risk Tolerance | Beta distribution | Models conservative‑skewed investor preferences |
| Loss Aversion | Gaussian | Consistent with prospect theory |
| Stress Tolerance | Normal | Behavioural stability |
| Investment Horizon | Categorical | Reflects real investor goals |

---

### ✔ 2. Embedded Behavioural Correlations  
We encoded realistic behavioural relationships, such as:

- Higher loss aversion → lower risk tolerance  
- Longer horizon → higher acceptable risk  
- Higher income → stronger risk capacity  
- Higher stress → preference for low‑volatility assets  

These correlations are derived from behavioural finance and ML‑driven risk modelling studies.

---

### ✔ 3. Generation Methodology

The dataset was generated using:

- **NumPy** for statistical sampling  
- **Pandas** for assembling the data structure  
- **Rule-based correlation constraints**  
- **Balancing procedures** for fair ML training  
- **Validation tests** to ensure realism  

Final dataset size: **20,000 synthetic investor profiles**.
